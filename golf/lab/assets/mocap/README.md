# Golf motion capture (CMU subject 64)

From the CMU Graphics Lab Motion Capture Database (mocap.cs.cmu.edu), subject 64 "golf":
64_01–64_10 swings, 64_11–64_15 putts. BVH conversion by Bruce Hahne (cgspeed, 2010 release), via
github.com/una-dinosauria/cmu-mocap. Frame 1 of each file is an added T-pose; 120 fps.
