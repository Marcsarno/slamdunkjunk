# Where the farts come from

All nine are real recordings taken from two open-source npm packages. Each was trimmed of silence, made
mono, levelled to about the same loudness (with a limiter so nothing clips) and saved as 96 kbps MP3.

| File | Used for | Source file |
|---|---|---|
| `classic.mp3` | The Classic | shartjs 1.1.2 `farts/fart2.wav` |
| `squeaker.mp3` | The Squeaker | shartjs `farts/fart1.wav` |
| `blat.mp3` | random only | shartjs `farts/fart3.wav` |
| `wet.mp3` | The Wet One | terminalfart 1.1.1 `sounds/wet.mp3` |
| `thunder.mp3` | The Thunder | terminalfart `sounds/hellacious.mp3` |
| `long-haul.mp3` | The Long Haul | terminalfart `sounds/done-long.mp3` |
| `toot.mp3` | random only | terminalfart `sounds/toot.mp3` |
| `dry.mp3` | random only | terminalfart `sounds/dry.mp3` |
| `poop-toot.mp3` | random only | terminalfart `sounds/poop-toot.mp3` |
